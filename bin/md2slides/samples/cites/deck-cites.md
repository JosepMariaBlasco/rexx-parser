# The parser {#parser kicker="Where this began"}

The Rexx Parser is a tokeniser and syntax analyser for classic Rexx
[@blasco2024parser]. It marks up the fenced code you see in these very slides.

Its subject language is the one described by Cowlishaw [@cowlishaw1990], whose
grammar the parser follows.


# Multiple sources on one point {#multi kicker="Grouped citations"}
